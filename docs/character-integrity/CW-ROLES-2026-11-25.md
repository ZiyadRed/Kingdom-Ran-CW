Gokei's 不退の迎撃 (MP 2000): allied Wei Fire Dragon generals, 呉鳳明 and 乱美迫 reflect attacks from cavalry
generals (3 times); allied Wei generals ATK +20%; all enemy generals DEF −20%. Source effect IDs
3680,3681,3682,3683,1019,3684,3685. The four reflect rows are effectType 177 (value1 3 = count, value2 1 = cavalry)
on self, group 6 (Wei Fire Dragon), character 149 and character 183. Gokei is classified Wei Fire Dragon on the site, so
`Ally Wei Fire Dragon` covers the self row. Reflect is a new mechanic with no numeric stat, so it is shown but never
added to buff totals (`parseBuffEffect('Reflect Cavalry Attacks')` is empty).

Goumasho's 至強の軍略【剛摩諸】 (MP 1000): self DEF +40%; allied Kanmei Army critical damage +30%; heals allied Kanmei
Army by 20%. Source effect IDs 3295,1751,3686,1867,3687. Goumasho belongs to the Kanmei Army, matching the self rows
1751/1867.
